# 📱 Installation & Mobile APK Guide

Play Intelligent Ludo on Web, local servers, or Android devices.

---

## 🌐 1. Web Browser (Instant Play)

Visit the live web app link:
👉 `https://Kartikey-Garg.github.io/Intelligent-Ludo/`

Works in Chrome, Safari, Firefox, and Edge on Android, iOS, iPadOS, macOS, Windows, and Smart TVs with 0 downloads required!

---

## 📲 2. Install Android APK (`.apk`)

1. Open your GitHub repository on a phone or PC:
   `https://github.com/Kartikey-Garg/Intelligent-Ludo`
2. Go to the **Actions** tab.
3. Select the latest successful workflow run (**Build Android APK**).
4. Download **`Intelligent-Ludo-APK`** under Artifacts.
5. Transfer the `.apk` file to your Android phone or tablet and tap **Install**!

---

## 💻 3. Local Production Preview

Run a lightweight local preview server on your computer:
```bash
npm run build
npm run preview
```
Access at `http://localhost:3000/`.
